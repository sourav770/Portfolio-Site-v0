# Portfolio-Site-v0

Responsive Video Editor & Motion Designer Portfolio Website for Sourav, recreated from dark editorial reference design.

## Features
- **Hero Section**: High-contrast typography (`MY`, `PORTFOLIO`), software badges (`Premiere Pro`, `After Effects`, `DaVinci Resolve`, `Photoshop`, `Blender`), and glowing accents.
- **Showreel Box**: 5x5 grid frame mesh with monogram `S` backdrop, top-right red L-bracket, vertical label `PORTFOLIO-ARCHIVE-2025`, status badge `19 / 09`, curved red dashed arrow, and video player lightbox modal.
- **Featured Showreel & Stats**: Video preview card and animated stats strip (`150+` Videos, `25M+` Views, `4+` Years Exp, `100%` Satisfaction).
- **Project Gallery**: Category filter tabs (`Commercials`, `Motion FX`, `Reels & Shorts`, `Color Grade`) with interactive project cards.
- **Workflow & Contact**: 4-step editing timeline, inquiry form with project type pills, copy email button, and toast notifications.

## Quick Start
Open `index.html` directly in any web browser.
